# Aurabot Soul

Aurabot Soul is a DeepSeek Harness QQ companion plugin based on Aurabot. It explores how personality, memory and emotional state can influence conversation.

## Changes

- Emotional state can influence tone and expression. Responses depend on the model and conversation context.
- Reply generation and delivery handling have been adjusted to reduce confusion between draft text and sent messages.
- Personality and memory handling have been refined.
- A Bilibili QR login provider is integrated.
- Connection and settings handling have received fixes.

## Getting started

DeepSeek Harness, Node.js 22.13 or newer, and a OneBot v11 QQ gateway are required. Install the plugin, restart DSH, configure the QQ accounts and gateway, and use dry-run mode before enabling message delivery.

See [the user manual](docs/USER-MANUAL.md) for details.
