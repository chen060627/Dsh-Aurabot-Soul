## 关于 Aurabot Soul

Aurabot Soul 基于 Aurabot 修改，关注 AI 伙伴在长期聊天中的人格、情绪、记忆与表达。你可以通过 QQ 与配置好的人格交流，让她根据当前对话和状态回应。

这个版本的出发点，是让角色的说话方式能够随经历和情绪变化：开心时可以轻快，受伤时可以坦诚表达，持续的冲突也可能影响耐心与交流意愿。实际表现由所选模型、人格、记忆及聊天上下文共同决定。

## Soul 版本的调整

| 方向 | 这个版本关注的内容 |
| --- | --- |
| 情绪与表达 | 让情绪状态参与回复，支持难过、委屈、生气等不同状态 |
| 人格与记忆 | 围绕人格状态和对话上下文进行整理，支持在面板配置 |
| 消息投递 | 调整回复与发送环节，减少过程性文字和实际回复混淆 |
| 哔哩哔哩 | 整合扫码登录入口，通过手机确认账号登录 |
| 连接与设置 | 对连接重试、设置保存及异常处理进行修复 |

## 功能介绍

### 💬 QQ 对话

通过支持 OneBot v11 的网关连接 QQ，在私聊和群聊中按面板配置接收及回复消息。可根据需要调整聊天规则、权限与模块开关。

### 🎭 人格、情绪与记忆

在面板里编辑人格设定，查看和管理相关功能。情绪系统会结合对话变化，影响角色的表达倾向。记忆帮助角色在后续聊天中利用保存的上下文。

### 🎙️ 语音与表情

根据所启用的模块及服务配置，使用语音、表情等方式丰富交流。具体可用能力取决于环境与模块配置。

### 📺 哔哩哔哩

在功能页面通过二维码登录，手机确认后使用账号相关功能。二维码失效时可重新生成。模块中的自动任务及评论功能应根据自己的需要配置。

### 🧩 模块管理

在面板中查看、启用或关闭模块，并根据模块说明完成配置。模块市场使用第三方来源，具体功能与许可请查看对应模块说明。

## 快速开始

### 1. 准备环境

- DeepSeek Harness。
- Node.js **22.13 或更高版本**。
- 支持 **OneBot v11** 的 QQ 网关及机器人账号。
- 可用的模型服务，并在 DSH 中完成配置。

### 2. 安装插件

下载本仓库的源码并解压。确认插件目录中可以看到 `package.json`、`cordis.patch.yml`、`src` 和 `client`。在 DSH 插件管理中添加该目录，完成依赖安装后重启 DSH。

### 3. 连接 QQ

在侧边栏打开 Aurabot Soul，按向导填写机器人 QQ、主人 QQ 和网关连接信息。连接后核对账号，确认机器人账号与设置一致。

### 4. 配置并试运行

选择或编辑人格，按需要启用情绪、记忆和其他模块。先使用试运行检查日志和回复，确认设置后再开启实际发送。

### 5. 按需登录哔哩哔哩

在对应功能页面打开扫码登录，使用手机扫码并确认。首次使用相关独立功能时，按页面提示完成其依赖配置。

## 常见问题

**连接成功后没有回复？** 先检查机器人账号是否核对成功、总开关与试运行状态，再检查聊天权限、网关状态和面板日志。

**为什么回复没有明显表现出情绪？** 情绪只是影响回复的因素之一。检查情绪功能是否启用，并结合人格设定、模型能力和近期对话观察。

**二维码过期或登录失效怎么办？** 回到登录页面重新生成二维码，并在手机上确认。账号状态及网络情况可能影响登录。

**如何迁移数据？** 可使用面板中的备份功能保存配置和相关数据，再按面板提示恢复。迁移前建议先核对备份内容。
