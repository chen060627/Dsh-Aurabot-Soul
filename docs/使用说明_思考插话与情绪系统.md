# Aurabot 思考插话与情绪系统使用说明

## 安装

1. 建议先在现有 Aurabot 面板的「系统 → 备份」保存一次当前配置和数据。
2. 将压缩包完整解压，在 DSH 的插件管理界面选择添加本地插件，路径指向解压后的 `dsh-aurabot-qq` 文件夹（该文件夹内应有 `package.json`）。安装后重启 DSH。已有配置、人格、记忆和 QQ 登录数据应沿用原数据目录；不要删除原数据目录。
3. 进入 Aurabot 面板，确认启用并检查 QQ 连接。请先用试运行或不涉及真实操作的聊天测试；不要直接用官方 GitHub 更新命令覆盖本定制版。

## 连续发消息

私聊默认先按连发等待时间合并消息。已经开始回复时，后续新消息等待当前回复投递完毕再处理。可以在聊天设置中单独开启「私聊思考时接收补充」，此时模型可能重新生成回复。群聊同一人的补充由群聊开关控制。

QQ 投递以网关返回的消息编号确认。被过滤、未发出或只有部分内容获得回执时，下一轮会带上投递情况。回复状态随会话保存。已送出的文字仍可能被平台延迟展示，回执不等于对方已读。

## B 站替代插件

此版本随包整合 dsh-bili-scroll 2.5.2，安装时需要让 DSH 完成依赖安装。安装后重启 DSH，进入 Aurabot 的 B 站页面，点击「手机扫码登录」，使用手机哔哩哔哩扫描并确认。页面自动查询确认结果。二维码过期时点击刷新。

dsh-bili-scroll 负责扫码及本机账号凭据。Aurabot 的视频、字幕、评论、弹幕、截图和 QQ 分享读取这份凭据继续使用。新插件独立的定时刷视频和自动评论默认关闭，可在其设置页按需开启。扫码和 Aurabot 原有功能无需先安装新插件的 Python 环境，使用新插件独立的 MCP、转写等功能时按其设置页安装依赖。

账号失效后需要重新扫码。短暂网络错误会显示暂时无法核验，30 秒后可重新检查。此包保留了升级前的配置，但 B 站登录入口已改用替代插件。备份恢复或更换电脑后，B 站需要再次扫码登录。

## 情绪

在「人设 → 情绪系统」可以查看和单独调整各类情绪强度及最近变化，调整敏感度、恢复速度和心情基线，也可以只重置当前人格的情绪。修改参数后请点「保存设置」。原有心情数据与记录自动兼容，每个人格分别保存。

「结合人格智能判断」启用后，她会结合人格卡和对话语境分析并修正情绪，下一次交流也会受到影响。它可能每轮额外调用一次模型，产生相应费用；不可用时会退回本地的简化判断。升级会保留原来的开关：如果旧配置把模型心情判断关了，请手动打开并保存。

情绪是对对话内容的模拟判断，表达方式受当前人格、模型和上下文影响；安慰、道歉与时间可能让情绪缓和，并不保证每句话都得到完全一致的判断。
